YT-Desktop 首个开源版本。

- Windows、macOS（Apple Silicon / Intel）、Linux 桌面客户端。
- 中英文界面、视频列表解析、单个与批量下载。
- YouTube 浏览器会话连接与 Cookie 文件导入。
- SQLite 下载队列、暂停继续、重试、限流冷却、文件校验。
- 启动自动检查版本、签名更新包校验、下载安装与重启。
- 画质格式、字幕封面、代理、组件安装更新与 CSV 导出。

运行时需要 yt-dlp、ffmpeg、ffprobe、Deno；可在偏好设置中安装。
安装包暂未配置 Windows 商业代码签名或 Apple 公证。
网站可下载性与会话权限取决于网站和 yt-dlp 当前支持范围。
